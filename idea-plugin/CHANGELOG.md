# Changelog

## 0.1.18

- 修复原生模式下连续点击条目卡顿：点击加 120ms 防抖，快速连点只渲染最后一次，避免每点一次就重建一套原生编辑器把 EDT 排满
- 原生模式增加按文件缓存（改前/改后文本），打开预览时后台预热全部文件，点已看过的文件不再读盘、不再重套补丁

## 0.1.17

- 预览对话框新增「原生对比」渲染：内嵌平台 `DiffRequestPanel`（真实编辑器，虚拟化 + 增量重绘 + 语法高亮），由 `preview.nativeDiff` 开关控制，默认开启
- 原生模式按补丁 hunk 的行号把改动还原成整文件的「改前 / 改后」再对比，行号、上下文、语法高亮与 IDEA 自己的对比窗口一致；hunk 行号对不上时退化为片段对比
- 原生面板用反射构造，任一环节失败（类缺失、构造失败、请求渲染异常）自动回退内置自绘列表，不会让预览对话框打不开
- 对话框未显示时先缓存待渲染请求，等 window 就绪再渲染，避免拿不到 Window 导致面板创建失败

## 0.1.16

- 修复统一视图不满宽：内容窄于视口时列表跟随视口宽度，行底色铺满整块区域（原来只有文字那么宽）
- 修复中文乱码：patch / 命令输出先按 UTF-8 严格解码，遇到非法字节回退 GB18030，GBK 源码项目的中文注释不再显示为乱码
- 继续优化点击响应：打开预览时就在后台把所有文件的 diff 行数据预处理完，点击条目只剩一次内存赋值；行配色常量提到绘制外，不再每次绘制 new JBColor（JBColor 构造会登记进全局主题更新表）

## 0.1.15

- diff 区域从 `JTextPane` 改为固定行高的自绘列表：只绘制可见行，不再有文档整体排版，切换/点击文件即时响应
- 修复并排视图两栏逐行错位（表现为「统一和并排内容不一致」）：长行不再按宽度折行，左右两栏固定行高、行数严格一致，缺失侧用空白行占位
- 统一 / 并排共用同一份行数据模型，切换视图不再重新构建（原来每种模式各自缓存一份文档）
- 文件路径与改动行数（+n / -m）上移到 diff 区顶部固定标题，两种视图都显示，不再作为正文第一行
- 支持右键「复制此行 / 复制全部」；并排模式左右两栏选中同一行

## 0.1.14

- 修复预览对话框 diff 区域「全是空白」：后台线程渲染完成后用 `invokeLater` 默认的 `NON_MODAL` 模态状态投递，会被模态的预览对话框一直挡在队列里不执行；改为 `ModalityState.any()` 投递，并加上失败后回退到 EDT 同步渲染的兜底

## 0.1.13

- 去掉「对比方式」文案；统一 / 并排改为 18px 自绘分段控件，并移到下方提示行右侧，不再单独占一行
- 并排对比补上 +/- 前缀：左侧删除行 `-`、右侧新增行 `+`，未变行不加
- 继续治理卡顿：diff 文档改为后台线程拼装后整体替换（原来在 EDT 上逐行 `insertString`，上千行会反复触发文档事件与重排）；新增文档缓存与 400 字符长行截断

## 0.1.12

- 深度修复预览：新增「统一 / 并排」两种对比方式，并排时左「修改前」右「修改后」、滚动联动、增删行带底色
- 修复点击文件卡顿与偶发无响应：diff 面板改为不换行的等宽面板（长行不再触发昂贵的折行计算），单文件渲染上限 1500 行并提示截断；勾选框状态变化也会同步刷新该文件 diff

## 0.1.11

- 深度修复预览：文件列表改为「勾选框 + 可点击文件名」，单击文件即时查看该文件的 diff，修复前只能看到一坨混合补丁
- diff 逐行着色：新增绿、删除红、@@ 段蓝、文件头灰，并在顶部显示该文件的 +N / -N 统计
- 预览对话框改为上下可拖动的 `Splitter`，并放大到 980×680

## 0.1.10

- 用 IDEA 原生 `Splitter` 替换 `JSplitPane`：表格与详情之间的分隔条从 10px 浅色粗条变成 1px 主题色细线
- 全站改用细滚动条（透明轨道 + 6px 圆角滑块），去掉深色主题下那条白色粗滚动条
- 进度条回到 8px、猫咪回到 22px，进度区高度 40px，不再过小

## 0.1.9

- 进度条改为 4px 细线 + 主题强调蓝（不再取 ProgressBar.foreground，深色主题下那是白色）；未知进度用同色光带扫动
- 猫咪缩小到 18px，整条进度区高度从 56px 降到 30px
- 修复深度修复在后台线程弹对话框导致的「Access is allowed from EDT only」失败：所有确认对话框统一切到 EDT

## 0.1.8

- 等级与来源筛选改为整条自绘：高度按字体度量固定，窗口变窄只压缩内边距，不再裁掉等级/来源
- 来源标签条去掉 JBTabs 的溢出菜单与上下箭头，选中项加粗 + 主题色下划线
- 修复点击「0 项」来源时列表跳回其他来源内容的问题：选中状态不再被自动重置
- 空结果时显示占位提示，不再只剩一块空白

## 0.1.7

- 来源筛选从下拉框改为官方 JBTabs：全部 / 代码质量 / 密钥泄露 / 静态缺陷 / 依赖漏洞
