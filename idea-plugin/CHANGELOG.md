# Changelog

## 0.1.6

- 标签页改用官方 JBTabs，与 IDE 工具窗口外观一致
- Action 补齐 `getActionUpdateThread`，服务统一用 `project.service<T>()` 获取
- 最低支持版本按所用架构 API 调整为 2023.3（233），不再只支持最新版

## 0.1.5

- 等级筛选标签改为按内容宽度紧凑排列，不再整行拉伸成超大按钮
- 统计信息移到等级标签行右侧并弱化字号，搜索框改为整行铺满
- 按 2026.3 官方 UI 规范调整间距与字号，仅支持 IDEA 2026.3 及以上版本

## 0.1.4

- 等级筛选标签改为圆角胶囊样式，选中带等级色底 + 彩色描边，取消后变灰
- 问题列表增加斑马纹，长列表更易读
- 搜索框增加占位提示文案

## 0.1.3

- 单击问题列表任意一格即定位到对应文件与代码行（不必再双击，也不限定点「位置」列）
- 定位改为按逻辑行列摆放光标：不再依赖字符偏移，避免文档未加载、换行符差异导致跳错行
- 行号越界时钳制到文件最后一行，打开失败仍有通知提示

## 0.1.2

- 列宽可拖动并自动记忆，双击表头分隔线可让该列自适应内容；内容不再被统一压缩成省略号，超出部分支持水平滚动、悬停提示
- 空闲状态不再显示进度条，扫描结束后收起并立即释放布局占位
- 严重程度彻底分色：顶部「严重 / 高危 / 中危 / 低危 / 提示」标签按等级着色，列表中级别单元格用等级色文字 + 浅色底区分
- 详情区在未选中问题时显示操作提示，不再留空

## 0.1.1

- 来源下拉框显示各来源的条数（如「密钥泄露 (126)」），条数随等级、搜索条件实时变化
- 问题列表按来源分组展示，单击分组标题即可折叠 / 展开，工具栏新增「展开全部 / 折叠全部」
- 单击「位置」列直接跳转到对应代码文件与行号，双击整行同样跳转；打开失败时弹窗提示原因

## 0.1.0

- 首个 IntelliJ IDEA 版本：Checkstyle / Gitleaks / Trivy / SpotBugs 四类扫描、深度修复、依赖升级
